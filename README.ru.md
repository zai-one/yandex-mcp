# Yandex MCP

**Реклама, аналитика и поисковые данные Яндекса — в одном диалоге.**

Разбирайте кампании Директа, статистику Метрики, поисковый спрос и диагностику Вебмастера с одним ассистентом. Yandex MCP объединяет пять групп API: настройте нужные для вашей задачи сервисы и добавляйте остальные по мере необходимости.

[Установка](#установка) · [Подключение к ассистенту](#подключение-к-ассистенту) · [Issues](https://github.com/zai-one/yandex-mcp/issues)

Например, попросите ассистента:

> Покажи мои счётчики Метрики. Для выбранного счётчика сравни визиты и достижения целей за два равных периода и выдели самые заметные изменения.

## Что можно сделать

| Задача | Возможности MCP |
|---|---|
| Директ | Кампании, поддерживаемые рекламные объекты и статистика; управляемые изменения при включённой записи. |
| Метрика | Счётчики, цели и статистические отчёты. |
| Search API | Асинхронные задания поисковой выдачи Яндекса с сохранёнными результатами. |
| Wordstat | Популярные запросы, динамика спроса, распределение по регионам и дерево регионов. |
| Вебмастер | Индексация и диагностика сайта, статистика запросов, работа с sitemap и переобходом. |

## Установка

Хотите установить готовый пакет? [Установка релиза и создание конфигурации клиента](INSTALL.md#install-a-release-package) работают без клонирования исходников.

Нужны **Python 3.12–3.14** и [uv](https://docs.astral.sh/uv/getting-started/installation/). Можно клонировать проект через Git или [скачать ZIP](https://github.com/zai-one/yandex-mcp/archive/refs/heads/main.zip). Для ZIP откройте распакованный каталог и пропустите первые две команды.

У каждой группы API свои учётные данные. Настройщик начинает с Метрики; для Директа, Вебмастера и Yandex Cloud добавьте доступы к нужным сервисам. Для Cloud Search также нужен ID каталога. См. [настройку сервисов](INSTALL.md#from-a-clone-or-source-zip).

```sh
git clone https://github.com/zai-one/yandex-mcp.git
cd yandex-mcp
uv sync --frozen --extra standalone
uv run --frozen --extra standalone python scripts/configure.py
uv run --frozen --extra standalone yandex-mcp --config mcp.local.json --check-config
```

Настройщик создаёт локальную конфигурацию и сохраняет секреты в приватных файлах. Если конфигурация уже существует, он не перезапишет её. `--check-config` проверяет локальные настройки; доступ к аккаунту проверяется первым запросом ниже.

## Подключение к ассистенту

Добавьте конфигурацию в MCP-клиент, использующий раздел `mcpServers` (например, Claude Desktop или Cursor). Замените `/ABSOLUTE/PATH/` своим абсолютным путём; на Windows в JSON можно использовать `D:/Tools/`.

```json
{
  "mcpServers": {
    "yandex": {
      "command": "uv",
      "args": [
        "--directory",
        "/ABSOLUTE/PATH/yandex-mcp",
        "run",
        "--frozen",
        "--extra",
        "standalone",
        "yandex-mcp",
        "--config",
        "/ABSOLUTE/PATH/yandex-mcp/mcp.local.json"
      ]
    }
  }
}
```

Клиент сам запускает MCP-сервер. После обновления списка инструментов отправьте первый запрос. Для другого формата конфигурации используйте те же `command` и `args`; `uv` должен быть доступен процессу клиента.

### Первый запрос

> Покажи мои счётчики Метрики и цели выбранного счётчика.

Базовая настройка начинается с Метрики. Если её токен принят, ассистент сможет показать доступные счётчики и прочитать их цели. Остальные группы API используют отдельно настроенные учётные данные.

Если инструменты не появились, проверьте абсолютный путь, доступность `uv` и результат `--check-config`. Для ошибки доступа проверьте учётные данные и права аккаунта. [Подробная установка и диагностика](INSTALL.md).

## Управление доступом и ограничения

Поисковым заданиям нужны отдельный worker и ID каталога Cloud. Wordstat использует доступы Cloud и явно заданные лимиты расходов. Запись зависит от прав сервиса и серверной политики. Интерактивная настройка OAuth и экспорт Metrika Logs не включены.

Для работы по сети предусмотрен HTTP с проверкой токенов. [Настройка HTTP](INSTALL.md#http), [конфигурация и права](docs/RUNTIME.md), [подключение Python-пакета](INSTALL.md#python-package-and-platform-integration).
